Upload of artefacts:

upload all the artefacts you created during your project in one single ZIP archive. 
Upload all your files in an editable format (pptx, doc,...) use this folder structure:

/application [folder containing your application form]
/protocols [e.g. review protocol,...]
/documentation [every type of documentation you created; e.g. architectureal description]
/SourceCode [sourcecode or link to public repo]
/presentation [editable file of your presentation]

Attention:

For all of your documents define a template including all relevant information (title page, what is it about, to which project does it belong, team members, headlines, page numbering, ...)

User manual:

Create a user manual which contains all necessary user credentials to run the application. create a brief description on how to use your application. (approx. 1-10 pages)

Deployment manual:

Create a description of all steps which are necessary to deploy your application. think about dependencies to other applications or libraries. (approx. 2-5 pages)

Presentation Video:

The video should last up to 5 min (max) 
The video should contain info about the idea of the project, the implementation, planning of the project as well as the current status.
Video Format: playable in VLC 3.0.11 standard config
